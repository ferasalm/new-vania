# Local CI runner

`tools/ci/run-local.mjs` runs the same checks as the GitHub Actions workflows,
so a branch can be validated before pushing.

| GitHub workflow | Local job | Commands |
|---|---|---|
| `.github/workflows/test.yml` | `test` | `npm test` |
| `.github/workflows/agent-validation.yml` | `agents` | `node tests/agents/validate.mjs`<br>`node tests/workflow/run-all.mjs`<br>`node tests/modules/validate-modules.mjs`<br>`npm run test:modules`<br>`npm run test:plugins` |
| both | `all` (default) | Both jobs; the plugin suite runs once via `npm test` |

## Usage

```bash
npm run ci                      # both workflows
npm run ci -- --job test        # test.yml only
npm run ci -- --job agents      # agent-validation.yml only
npm run ci -- --skip-install    # reuse the current node_modules
npm run ci -- --list            # show jobs and steps
```

Dependencies are installed with `npm ci` only when `node_modules/` is missing.
Use `--install` to force a clean install, or `--skip-install` to skip it.

## Exit codes

- `0` — every selected step passed.
- `1` — at least one step failed.
- `2` — invalid arguments or unsupported Node version.

## CI parity notes

- GitHub Actions runs Node 20. The runner warns when the local Node major
  version differs, but still runs the suite.
- The `agents` job runs `npm run test:plugins` because the workflow does.
  The `all` job skips that duplicate step because `npm test` already includes it.
- `tests/agents/validation-report.md` is generated by the validator and is
  git-ignored.
