# assets/processed — canonical concept→asset pass

First tracked MVP art assets of the project, processed from the locked concept
corpus into durable, editable `.aseprite` sources + Godot-ready exports.
Generated by the technical-artist canonical pass (branch
`feat/aseprite-canonical-pass`, 2026-11-16). Every step below is reproducible
from the named sources.

Palette references are the art bible's (`design/art/art-bible.md` §4,
`design/art/palette.json`). Naming follows art bible §8 (`snake_case`,
`spr_<subject>_<action>_strip.png`, adjacent frame-count/duration JSON).

## Deliverables per animation

Each animation ships as:

- `<name>.aseprite` — the editable source: one named layer, all frames as cels,
  the asset's own palette set (union of frame colors, luminance-sorted).
- `<name>_strip.png` — horizontal spritesheet (preview + atlas-slice source; **not a
  direct texture on mobile** — the three 48-frame Pandora strips are 11520×135,
  over the ~4096 px mobile GPU texture limit; see Godot notes).
- `<name>_strip.json` — Aseprite spritesheet metadata: per-frame rects **and
  durations** (the art bible §8 frame-count+fps record).
- `frames_<action>/<name>_fNN.png` — per-frame PNG exports (1-based, zero-padded).

## Processing recipe (reproducible)

### 1. Pandora GIFs — dithered chroma-key

The screens are **not** flat `#00FF00`: each GIF's background is a dithered
multi-tone green family (e.g. idle: `#249055/#246C55/#249000/#246C00…`).

1. Extract all frames (full-frame replaces; 60 ms each).
2. Key rule: green dominance `g > 1.15·max(r,b)` and `g ≥ 80`.
   - flood-fill from frame borders over keyable pixels (protects enclosed
     greens), then a global sweep for interior green pockets.
3. Palette-level defringe: any palette color with ≥ 50 % of its pixels adjacent
   to transparency and green-leaning (`g ≥ 24, g ≥ r, g ≥ b`) is keyed — removes
   background dither remnants without touching figure colors.
4. Inpaint isolated 1-px enclosed holes with the 8-neighborhood mode color.
   The source art's dark shading dither shares the screen's green family
   (green spill), which left 37,144 pinholes across 144 frames; all filled,
   re-verified zero enclosed holes.
5. Frames saved at native 240×135 / 135×240 (portrait jump), colors untouched.

Verified: **zero residual green-dominant pixels** in every keyed frame.

### 2. Attack sheet — grid verify → 6-pose slice → scale

1. Structure probe: the 2172×724 sheet has a 1-px dark border on all four edges
   and dark separator columns at x=724/x=1447; fine column profiling shows the
   poses are **two per 724-cell** (six poses total), bridged by thin motion
   streaks.
2. Pre-crop the border; slice six cells at the profiled gap positions /
   density minima: `[1,359) [359,699) [699,1070) [1070,1510) [1510,1841)
   [1841,2171)`.
3. Key per cell: flood green-dominance `g > 1.25·max(r,b), g ≥ 4` (the sheet's
   dark-green separator lines run at g 5–16), then global sweep `g ≥ 80`
   (figure is black/teal/navy — never green-dominant), then the same defringe.
4. Pose bbox from **dense** columns/rows only (≥ 2 opaque px) — 1-px noise
   streaks cannot inflate it.
5. BOX downscale ×0.3439, shared 40-color MEDIANCUT quantize (no dither, per
   art bible §6), bottom-aligned (feet planted) center-x on a 146×151 canvas.

Frame order = sheet order left→right: windup → raise → strike (cyan arc) →
follow-through → recovery. Committed-arc strip per art bible §5 evidence
standard.

### 3. Arnetria — white key → scale to 2.75× player

1. Pose crops from the 1024×1024 sheet (text labels `IDLE (FLOATING)` /
   `CAST` / `ATTACK` and the bottom caption excluded by crop bounds):
   idle `[80,26,476,516]`, cast `[536,26,990,518]`, attack `[230,536,912,976]`.
2. White key: flood from crop edges over `min(r,g,b) ≥ 240`, then a global
   sweep at `min(r,g,b) ≥ 246`, defringe `min ≥ 225` (JPEG halo). **The sweep
   keys any pixel with min ≥ 246, enclosed or not — enclosed pure whites (dress/
   glass highlights reading ≥ 246) go with it; only enclosed whites below the
   threshold survive.** The pass verified 0.00 % near-white residue, which is the
   sweep's own result.
3. Tight-crop, BOX downscale to height 360 (2.75 × 131), 40-color quantize
   (denial render: 48). Re-verified: **0.00 % opaque near-white** in all four.
4. `arnetria-denial.jpg`: crop `[96,0,944,948]` (includes the detached left
   shawl strands at x≈100–168, excludes the bottom text band), same key/scale.

### 4. `.aseprite` assembly & exports

- Each frame PNG imported as a cel into one named layer; sprite palette set to
  the union of the asset's frame colors, luminance-sorted; durations as in the
  table.
- Bulk cel assembly was driven through the project container's Aseprite CLI
  (`/workspace/setup/aseprite/aseprite` — the same engine the Aseprite MCP
  drives) with generated Lua scripts; the MCP tools performed all verification
  (sprite info / palettes / pixel reads) and every spritesheet export.
- Strips exported horizontal, 0 padding, with JSON metadata.

## Could not recover / known limitations

1. **Element separation**: Arnetria's clock ring and floating shards are baked
   into her pose sprites (they render behind the figure; a clean layer split is
   impossible from these sources). The ATTACK pose's shard spray is likewise
   baked (it is the pose's read); live projectiles should use `mirror_shard`.
2. **Slash-sheet motion streaks**: the thin streaks bridging poses were cut at
   pose boundaries (dense segments kept with their pose; 1-px noise dropped).
3. **Green-family sparkle in dash/jump** was keyed with the screen — greens are
   not in the palette; the rim-light rule (§3) wants the glow-family cyan rim.
4. **Jump streaks clip at frame edges** — source composition; kept at native
   135×240.
5. **Arnetria edge alpha** is soft (1-px BOX-averaged) from downscaling;
   Pandora frames are binary 1:1 with zero resampling.
6. **Attack timing** (70 ms/frame) is an authored default — the sheet carries no
   timing; and §5's recovery padding (+2–3 frames) is left as an art-direction
   follow-up rather than invented here (6 sourced poses only).
7. **Attack horizontal registration** is center-neutral per frame; the source
   cells do not preserve body registration — in-engine per-frame offsets may be
   tuned by gameplay programming.

## Godot notes

- Import PNGs with nearest-neighbor filtering (project default
  `default_texture_filter = Nearest` per art bible §8), mipmaps off.
- **Per-frame PNGs are the platform-safe import path** (240×135 and smaller — every
  target). The horizontal strips are preview/atlas-slice artifacts; any strip wider
  than ~4096 px (the three 48-frame Pandora strips at 11520×135) must NOT be
  imported as a direct texture on mobile targets — Godot documents the typical
  mobile GPU limit at 4096×4096. Slice them via the JSON, or use the frames.
- `*_strip.json` is Aseprite spritesheet format (frame rects + durations) —
  directly consumable by atlas-slicing importers.
- The `.aseprite` files are the edit-here sources of truth; regenerate strips
  from them after any edit.
